1. iOS MDM คืออะไร และทำงานอย่างไร?

MDM (Mobile Device Management) คือระบบที่ทำให้แอดมินสั่งการควบคุมเครื่อง iPhone/iPad จากระยะไกลผ่านอินเทอร์เน็ตได้ โดยไม่ต้องจับตัวเครื่องจริง

[แอดมินกดปุ่มบนเว็บ RentControl] ↓ (HTTPS) [เซิร์ฟเวอร์ RentControl Backend] ↓ (HTTP/2 + APNs Certificate) [Apple Push Notification Server (APNs)] ↓ (สัญญาณเงียบ "Wake Up") [เครื่อง iPhone ของลูกค้า] ↓ (ดึงคำสั่งจากเซิร์ฟเวอร์เรา) [เครื่องดำเนินการ: Lock / Unlock / ติดตั้งนโยบาย]
💡 ข้อดีสำคัญ
ระบบ MDM ใช้ช่องทาง APNs (เดียวกับที่ LINE ใช้ส่งแจ้งเตือน) เพื่อ "ปลุก" เครื่อง ทำให้คำสั่งถึงเครื่องภายใน 2-3 วินาที แม้หน้าจอเครื่องจะปิดอยู่

3. ขั้นตอนการเปิดใช้งาน iOS MDM (ทุกรูปแบบ)

📋 สิ่งที่ต้องเตรียมเหมือนกันทุกรูปแบบ — APNs Push Certificate

⚠️ จำเป็นต้องมีไม่ว่าจะใช้รูปแบบใด
APNs Certificate คือ "ใบอนุญาต" ที่ Apple ออกให้เซิร์ฟเวอร์เรา เพื่อยืนยันว่าสิทธิ์ในการส่งสัญญาณไปยังเครื่อง iOS ใน Fleet ของเราถูกต้องตามกฎหมาย ขาดไม่ได้ครับ
1
สร้าง CSR File ด้วย OpenSSL (บน Windows หรือ Mac ก็ได้)
เปิด Command Prompt / Terminal แล้วรันคำสั่ง:
openssl req -out mdm.csr -new -newkey rsa:2048 -nodes -keyout mdm_push_key.pem
จะได้ไฟล์ 2 ไฟล์: mdm.csr และ mdm_push_key.pem
2
ขอ Push Certificate จาก Apple Push Portal (ฟรี)
เข้าเว็บ identity.apple.com → "Create a Certificate" → อัพโหลด mdm.csr → ดาวน์โหลด MDM_Certificate.pem
3
วางไฟล์ใน backend/certs/ และตั้งค่า .env
backend/certs/mdm_push_cert.pem  ← ไฟล์จาก Apple
backend/certs/mdm_push_key.pem   ← ไฟล์จากข้อ 1
เพิ่มใน backend/.env:
APPLE_MDM_TOPIC=com.apple.mgmt.External.xxxx-xxxx
APPLE_MDM_PUSH_CERT_PATH=./certs/mdm_push_cert.pem
APPLE_MDM_PUSH_KEY_PATH=./certs/mdm_push_key.pem
4
Restart backend และตรวจสอบสถานะ
เข้าหน้า 🍎 iOS MDM Setup ในระบบ RentControl จะแสดงสถานะ ✅ Ready ทันทีหากตั้งค่าถูกต้อง

📱 ขั้นตอนลงทะเบียนเครื่อง — แบบ OTA Web (ไม่มี ABM ไม่มี Mac)

1
เปิด Safari บนเครื่อง iPhone ที่ต้องการลงทะเบียน
เข้าที่ URL: https://yourserver.com/ios-enroll (ต้องเป็น HTTPS เท่านั้น)
2
กดดาวน์โหลดโปรไฟล์และอนุญาต
Safari จะแจ้ง "Website is trying to download a configuration profile" → กด Allow
3
ติดตั้งโปรไฟล์ใน Settings
Settings → Profile Downloaded (ด้านบนสุด) → กด Install → ใส่รหัสผ่านเครื่อง → กด Trust
4
เครื่องเข้าระบบอัตโนมัติ
เครื่องจะส่ง CheckIn มาที่เซิร์ฟเวอร์ทันที และปรากฏในหน้า Devices Dashboard โดยไม่ต้องพิมพ์รหัสใดๆ

4. Screen Time Lockdown — ป้องกันลูกค้าลบโปรไฟล์ MDM

เมื่อลงทะเบียนเครื่องผ่าน OTA แล้ว ลูกค้าสามารถเข้า Settings เพื่อลบโปรไฟล์ควบคุมออกได้ ระบบ Screen Time Lockdown จะส่งโปรไฟล์ชั้นที่สองเพื่อปิดกั้นช่องทางนี้:

ฟังก์ชันบนเครื่องลูกค้า ก่อนส่ง Profile หลังส่ง Screen Time Lock
📷 กล้องใช้ได้ถูกบล็อค
🌐 Safariใช้ได้ถูกบล็อค
📲 App Storeใช้ได้ถูกบล็อค
🗑️ ลบแอปทำได้ถูกบล็อค
⚙️ Settings → VPN & Device Managementเข้าได้ถูกซ่อน
📞 โทรออก / รับสายใช้ได้ยังใช้ได้ปกติ
🔄 Factory Reset (เมนูล้างเครื่อง)กดได้⚠️ ยังกดได้อยู่
⚠️ ข้อจำกัดสำคัญ (OTA + Screen Time Lock)
ลูกค้ายังสามารถ ล้างเครื่อง (Factory Reset) ได้ผ่านเมนู Settings → General → Transfer or Reset iPhone เพื่อหลีกเลี่ยงการควบคุม ทางป้องกันเดียวที่แก้ปัญหานี้ได้ถาวรคือการใช้ ABM/DEP ครับ

5. ชั้นป้องกันแบบหลายระดับ (Defense in Depth)

🛡️
ชั้น 1 — Screen Time Lockdown Profile (ซอฟต์แวร์)
ปิดกั้นเมนูลบโปรไฟล์ MDM ใน Settings ลูกค้าทั่วไปที่ไม่รู้เรื่อง IT จะหาทางออกไม่เจอ ป้องกันได้ ~80%
🔑
ชั้น 2 — ตั้งรหัสเครื่อง + Screen Time Passcode โดยแอดมิน
ลูกค้าไม่รู้รหัสผ่าน → เข้า Settings ไม่ได้เลย → แก้ไขอะไรไม่ได้ทั้งสิ้น ป้องกันได้ ~90%
🔔
ชั้น 3 — ระบบแจ้งเตือน 24 ชั่วโมง (Offline Alert)
เมื่อเครื่องออฟไลน์นานเกิน 24 ชั่วโมง ระบบส่งอีเมล์แจ้งเตือนแอดมินทันที เพื่อให้โทรติดต่อลูกค้าก่อนสายเกินไป
📄
ชั้น 4 — สัญญาทางกฎหมาย + เงินมัดจำ
ระบุในสัญญาว่าการแก้ไขซอฟต์แวร์หรือ Reset เครื่องโดยไม่ได้รับอนุญาต = ชดใช้ราคาเครื่องเต็มจำนวน รับเงินมัดจำ 30-50% ไว้เป็นหลักประกัน

6. ปุ่มควบคุมบนหน้า Devices Dashboard

ปุ่มผลลัพธ์เมื่อไหร่ควรใช้
🔒 Lock ล็อคหน้าจอทันที (ลูกค้าใส่รหัสเองได้) ทดสอบการเชื่อมต่อ / แจ้งเตือนลูกค้า
🔓 Unlock ส่งคำสั่งปลดรหัสผ่านหน้าจอ หลังลูกค้าจ่ายเงิน
🔐 Screen Time Lock ปิดกั้น Safari/กล้อง/App Store/ลบโปรไฟล์ MDM ก่อนส่งเครื่องให้ลูกค้าทุกครั้ง
🔓 Screen Time Unlock คืนสิทธิ์ทุกอย่างให้เครื่อง เมื่อสิ้นสุดสัญญา/ลูกค้าซื้อขาด
🛡️ บล็อคฟีเจอร์ ตั้งค่านโยบายรายเครื่อง (กล้อง/USB/โทรออก) ตามเงื่อนไขแผนเช่าแต่ละลูกค้า

7. ต่ออายุ APNs Certificate ปีละ 1 ครั้ง (ฟรี)

1
เข้า identity.apple.com ก่อน Certificate หมดอายุ
ระบบ RentControl จะแสดงวันหมดอายุบนหน้า iOS MDM Setup
2
กดปุ่ม "Renew" (ห้ามกด Create ใหม่)
ต้องล็อกอินด้วย Apple ID เดิม และกด Renew เท่านั้น ไม่ใช่สร้างใหม่ เพื่อรักษา Push Channel ของเครื่องลูกค้าทุกเครื่อง
3
แทนที่ไฟล์เก่าบนเซิร์ฟเวอร์และ Restart
วาง mdm_push_cert.pem ใหม่ทับไฟล์เก่าใน backend/certs/ แล้ว restart backend — เครื่องลูกค้าทุกเครื่องใช้งานต่อได้ทันทีไม่สะดุด
🚨 หากสร้าง Certificate ใหม่แทนการ Renew
เครื่องลูกค้าทุกเครื่องที่เช่าอยู่จะหลุดออกจากการควบคุมทันที และต้องนำมาลงทะเบียนใหม่ทุกเครื่อง — ห้ามทำโดยเด็ดขาดครับ
